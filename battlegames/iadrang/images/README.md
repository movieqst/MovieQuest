# Photographs for the Battle of the Ia Drang

The introduction shows a picture beside each narrated screen and the unit
write-ups reuse them. The engine looks for the files below in this folder;
until a file is present it shows a "Photo to add" card with the caption.
Captions and reference lines live in `scenario.js` (each intro slide's
`media` list), so a photo can be swapped without touching the code.

Most of these are United States Army photographs, which are public domain.
Search Wikimedia Commons (or the US Army Center of Military History and the
National Archives) for the subject, save it here under the file name shown,
and check the `credit` line in `scenario.js` matches the source.

Sizes: 1200 px on the long side is plenty. JPEG keeps the folder small.
Files 11 and 12 are the hard ones: Vietnamese state photographs are not
always free to reuse. If no free picture turns up, leave the card as
"Photo to add" and the game still works.

The painted terrain, sprite sheets and portraits are described in
`ART-PROMPTS.md`; the layout guides are `iadrang-xray-layout-guide.png` and
`iadrang-albany-layout-guide.png`.
