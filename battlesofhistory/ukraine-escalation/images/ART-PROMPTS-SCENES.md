# Ukraine and Russia: Escalation, 1991–2014: scenes, title card and slide mount, one per chat (18 November 2026)

These are the painted scenes for the slideshow (the script's `art-*` slides), plus the title card and the slide mount.

**Owner's rule:** real people appear only in real photographs, never in these paintings. Every scene below is **empty of
people**. There is also no readable text, and no flags or emblems; the page adds captions on the slide mount itself.

**How:**
1. Open a NEW chat in ChatGPT for each picture.
2. Paste the text as one message.
3. Download the result as PNG and send it to Claude. Landscape 3:2 (1536 x 1024) fits the 35mm slides.

Every prompt starts with the same lines, so that each can be pasted alone.
