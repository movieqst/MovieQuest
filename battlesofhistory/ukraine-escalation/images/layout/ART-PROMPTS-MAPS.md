# Ukraine and Russia: Escalation, 1991–2014: the eight painted maps, one per chat (18 November 2026)

Made by `tools/draw-maps.py`. The land and sea come from real elevation data. The coast of the Kerch Strait comes from
OpenStreetMap. Central Kyiv's streets and buildings come from OpenStreetMap ((c) OpenStreetMap contributors, ODbL).

**The paintings show land and water only:** no borders, no names, no pipelines. The page draws the borders of the time, the
labels, the pipelines and the arrows itself, inside the old-style projector slides. The grey border lines on the guides are
only there to help find places.

**How (the same for every map):**
1. Open a NEW chat in ChatGPT for each map.
2. Attach `<map>-base.png` first, then `<map>-guide.png`.
3. Paste the text for that map as one message.
4. If ChatGPT offers **Edit** on the first picture, use it on the whole picture.
5. Download the result as PNG and send it to Claude.

If the coast comes back in the wrong place, reply: "The coastline is in the wrong place. Keep it exactly where it is in the
first picture."

Every prompt begins with the same paragraph (it is repeated in each one, so each can be pasted alone).
