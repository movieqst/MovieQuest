# Somalia 1988: how to say the Somali names

Checked 17 November 2026 from the rules of Somali spelling (the official Latin alphabet of 1972), in which every letter
has one sound. The names in the script use the usual English spellings (Hargeisa, Burao); the official Somali spelling
is given beside them, because it shows the sound:
- **x** is a strong breathy *h* (Muxumed = Mu-hu-med); **c** is a catch in the throat, usually silent in English
  (Cigaal = Egal, Burco = Burao);
- **dh** is a *d* said with the tongue curled back; **q** is a *k* made far back in the throat; **kh** as in Scottish *loch*;
- **double vowels are long**: aa as in *father*, ee as in *they*, ii as in *see*, oo as in *go*, uu as in *moon*;
- **ey** is like *ay* in *day* (Hargeysa = har-GAY-sa).

The capital letters show the stressed part. The last column is the spelling the computer voice is given (the page still
shows the normal spelling). Listen to `pronunciation-check.mp3`: each name is said first as written, then with the
new spelling. The best check is a Somali speaker: play them the file.
