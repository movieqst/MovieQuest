# Six-Day War: the remaining artwork (prompts for ChatGPT, 7 November)

Everything else is done and in the game: 34 unit sheets, the fallen of three armies, 7 leaders and all four maps.

## Paste this block once at the start of the chat
```text
I need sprite sheets for a historical strategy game about the Six-Day War, June 1967, in the same painted-pixel style as the sheets you made before.
EVERY SHEET:
- ONE square image, 1024 x 1024 or larger, a 4 x 4 grid of equal cells on a flat pure green background (#00FF00). Nothing else in the image.
- Rows, top to bottom: facing the viewer (south), facing RIGHT (east), facing away (north), facing LEFT (west). The four columns are four frames of the action.
- One figure per cell, the whole figure inside its cell, the same size in every cell, seen from a 3/4 top-down angle.
- No text, numbers, labels, flags on sleeves, or blood. No bright green anywhere on the figure.
- Name each file exactly with the bold name I give, send each as its own PNG at full size (no previews, no contact sheets, no combined concept images).
- Paint the face from the reference photo, adjusted to the person's age in June 1967.
```
