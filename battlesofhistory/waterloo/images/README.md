## Intro slideshow ("From the record")

The engine looks for these files here; until a file is present it shows a "Photo to add" card with the caption.
All the paintings are long out of copyright; on Wikimedia Commons pick a file marked public domain (paintings) or
CC BY / CC BY-SA (modern photos), and put the credit line in that entry's `credit` in `scenario.js`.
